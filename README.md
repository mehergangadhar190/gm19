# GM Manager

Clean Flutter source for the GM Manager personal Instagram/social-media manager concept.

Included workspaces:
- Dashboard
- Photo Studio and gallery selection
- AI Post Suggestions interface
- Instagram Stories
- Reels
- Collage Creator
- Highlights Manager
- Content Calendar / Planner
- Approval
- Analytics interface
- Drafts
- Saved Ideas
- Personal Style profile

The app keeps publishing user-controlled. Real AI image generation, Instagram API publishing, live Instagram analytics and cloud memory require external services and credentials; this source does not claim those services are already connected.
